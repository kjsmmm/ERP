# 迭代 3a：订单管理 + 库存基础

## Why

迭代 0-2 完成了基础设施、认证权限、客户管理、产品管理。当前系统可以管理客户和产品，但无法下单和管控库存。迭代 3a 打通"客户下单 → 库存管控"这条核心主干，让 ERP 系统具备基本的业务流转能力。

## What Changes

### 1. 订单管理模块（erp-order）
- 销售订单 CRUD：创建、查看、编辑、删除
- 订单状态机：草稿 → 已确认 → 生产中 → 已完成 → 已关闭（含取消、暂停分支）
- 订单明细：产品 + 数量 + 单价
- 订单与客户、产品关联
- 订单金额自动计算

### 2. 库存管理模块（erp-inventory）
- 仓库管理：仓库信息 CRUD
- 库存查询：按产品/仓库查看库存，区分实物量、预留量、可用量
- 入库管理：采购入库、生产入库、退货入库
- 出库管理：销售出库、生产领料、报废出库
- 库存预留：订单确认时冻结库存，防止超分配
- 库存流水：记录每次库存变动

## Capabilities

- **order-management**: 销售订单全生命周期管理，含状态机、明细
- **inventory-management**: 仓库、库存、入出库、预留、流水

## Impact

### 新增模块
- `erp-order`：订单管理后端模块
- `erp-inventory`：库存管理后端模块

### 修改模块
- `erp-boot`：新增模块依赖
- `erp-frontend`：新增订单、库存相关页面

### 数据库
- 新增表：sales_order, order_item, warehouse, inventory, stock_record
