## Context

迭代 0 和迭代 1 已完成，建立了完整的基础设施（Spring Boot 脚手架、认证权限、客户管理模块）。现有代码遵循模块化单体架构，每个业务模块独立 Maven 子模块，内部按 controller/service/mapper/entity/dto/vo/enums 分层。

迭代 2 需要新增产品管理和 BOM 管理，这是制造业 ERP 的核心，后续订单、生产、采购、库存模块都依赖它。

## Goals / Non-Goals

**Goals:**
- 产品 CRUD + 分类管理 + 多图上传 + 启用/停用
- BOM 物料清单管理，支持嵌套半成品，递归展开完整 BOM 树
- 图片存储到本地 uploads 目录，通过 Nginx 暴露访问
- 完全复用迭代 1 建立的代码模式（BaseEntity、Result、分页、权限校验等）

**Non-Goals:**
- 阶梯报价（后续迭代）
- 产品导入/导出（后续迭代）
- BOM 版本管理（后续迭代）
- 文件上传到 OSS/MinIO（当前只做本地存储）

## Decisions

### D1: BOM 采用邻接表 + 递归 CTE

**选择**: `bom_item` 表只存直接父子关系，查询时用 MySQL 8 递归 CTE 展开完整 BOM 树。

**备选方案**:
- 扁平展开存储：半成品 BOM 展开后直接存到成品的 bom_item 里。查询简单但更新半成品 BOM 时需要级联更新所有引用它的成品，数据一致性风险大。

**理由**:
- 数据一致性：半成品 BOM 改了，所有引用它的成品自动生效
- 标准做法：SAP、用友、金蝶都是邻接表模型
- MySQL 8 原生支持递归 CTE，性能完全满足 2-3 层嵌套
- 环检测在 Service 层用 Set 记录访问过的节点即可

### D2: 产品类型用枚举字段区分

**选择**: `product` 表加 `product_type` 字段（1=原材料, 2=半成品, 3=成品），不单独建类型表。

**理由**:
- 类型固定且少，枚举足够
- 决定业务逻辑：原材料不能建 BOM，半成品/成品可以
- 影响后续生产工单和库存管理的处理方式

### D3: 产品分类用扁平表 + parent_id

**选择**: `product_category` 表用 `parent_id` 字段支持两级分类（顶级 parent_id=0）。

**理由**:
- 工厂产品分类一般不超过两级（如：原材料 → 五金件）
- 扁平表简单，前端用树形组件展示即可
- 后续如果需要更深层级，parent_id 模型天然支持

### D4: 产品图片用独立表

**选择**: `product_image` 独立表，支持多图，标记主图。

**备选方案**:
- product 表加单个 image_url 字段。简单但不灵活。

**理由**:
- 产品展示需要多角度图片
- 主图用于列表缩略图，细节图用于详情页
- 独立表便于后续扩展（如图片排序、图片描述）

### D5: 文件上传存储在本地 uploads 目录

**选择**: 图片文件存储在服务器本地 `uploads/product/` 目录，数据库存相对路径。

**理由**:
- 当前阶段简单可靠
- Nginx 直接暴露 `/uploads/` 路径做静态资源
- 后续可平滑迁移到 MinIO/OSS，只需改存储实现类

### D6: BOM 更新采用整体替换策略

**选择**: 更新产品 BOM 时，先删除该产品的所有 bom_item，再批量插入新的。

**备选方案**:
- 逐条对比新旧 BOM 做增删改。逻辑复杂，容易出错。

**理由**:
- BOM 子项一般不多（几条到几十条），整体替换性能足够
- 逻辑简单，用 `@Transactional` 保证原子性
- 前端传完整的子项列表，后端直接替换

## Risks / Trade-offs

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 递归 CTE 环检测遗漏 | 无限递归导致查询超时 | Service 层用 Set 记录已访问节点，发现环立即抛异常；SQL 层加 `level < 10` 硬限制 |
| 图片文件占用磁盘空间 | 长期积累可能磁盘满 | 后续迭代加文件清理机制（删除产品时级联删除图片文件） |
| BOM 整体替换的并发问题 | 两人同时编辑同一产品 BOM 可能丢失数据 | 乐观锁或编辑锁，当前阶段可接受（用户量小） |
| 原材料被 BOM 引用后误删除 | BOM 数据不完整 | 删除产品前校验是否被 bom_item 引用，有引用则拒绝删除 |
