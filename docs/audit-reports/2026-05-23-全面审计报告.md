## 一、架构审计

### 1.1 模块结构

```
erp-common       (共享基础层: BaseEntity, Result, ErrorCode, 工具类)
  │
erp-system       (系统管理: 用户/角色/部门/权限/日志)
  │
erp-auth         (认证授权: JWT + Spring Security)
erp-customer     (客户管理)
erp-product      (产品管理 + BOM)
  │
  ├── erp-inventory    (库存管理)
  ├── erp-production   (生产管理: 车间/班组/设备/工艺/计划/工单/报工)
  ├── erp-order        (订单管理: 销售订单/发货/退货)
  ├── erp-purchase     (采购管理: 供应商/申请/采购单/入库)
  │     │
  │     └── erp-quality (质量管理: 检验标准/IQC/OQC/不合格品)
  │
erp-finance       (财务管理: 应收/应付)
erp-boot          (启动入口: 依赖所有模块)
```

无编译期循环依赖，分层总体合理。

### 1.2 架构问题

| # | 问题 | 严重度 | 文件 | 说明 |
|---|------|--------|------|------|
